BM Employee Attrition Analytics Dashboard (Power BI)A professional Power BI dashboard analyzing employee attrition across demographics, tenure, role, and compensation, built on the IBM HR Analytics dataset. This project focuses on transforming raw transactional HR data into interactive, executive-ready insights.OverviewThe goal of this project is to answer a critical business question: Where is employee attrition concentrated, and which cohorts present the highest risk to the organization?By tracking key HR metrics alongside granular employee segments, this dashboard empowers HR leaders to transition from reactive exit-interview tracking to proactive, data-driven retention planning.DatasetThe analysis is based on the IBM HR Analytics Employee Attrition and Performance dataset (available on Kaggle).Scope: 1,470 employees (historical records).Attributes: 35 features covering demographics (Age, Gender, Education), role specifics (JobRole, Department, JobLevel), tenure, compensation (MonthlyIncome, PercentSalaryHike), and historical attrition status ("Yes"/"No").Tools UsedPower BI Desktop: Core dashboard development, visualization design, and canvas layout.Power Query: Data extraction, column profiling, data type formatting, and initial transformation.DAX (Data Analysis Expressions): Custom statistical calculations and key performance indicator (KPI) metric definitions.Data Transformations & GroupingTo avoid cluttered visuals and reveal actionable generational trends, raw values were structured using specialized grouping models:Tenure Segmentation: Raw years at the company were grouped into clean operational bands using a logical conditional model:0-1 yr (Onboarding & critical transition phase)1-3 yr (Early career integration)3-5 yr (Mid-tenure)5+ yr (Established tenure)Equal Age Binning: To ensure a mathematically balanced, unbiased view across age groups, the numeric Age column was compiled into uniform 10-year equal brackets using Power BI's automatic binning tools:10-19 20-29 30-39 40-49
